# Quant Roadmap

## Phase 1: research dashboard

- Build a clean Streamlit dashboard
- Show market snapshot, price chart, and research notes
- Keep the app simple and easy to use

## Phase 2: signal engine

- Add quant scoring
- Add news-aware scoring
- Show signal summaries and risk notes

## Phase 3: prediction evaluation

- Add prediction storage
- Add evaluation for hit rate and realized returns
- Show learnings from past research ideas

## Phase 4: strategy lab and backtesting

- Add Strategy Lab
- Add simple backtesting outputs
- Add equity curve comparisons

## Phase 5: news-aware scoring

- Improve event-aware research summaries
- Improve sentiment and risk interpretation
- Keep explanations student-readable

## Phase 6: paper trading simulation

- Add simple portfolio simulation
- Compare allocations and historical outcomes
- Keep the simulator educational and research-only

## Phase 7: human-approved execution only after proof

- Only consider execution-related work after repeated proof
- Require human review before any real-money or live-trading idea moves forward
- Keep the project focused on research and learning until evidence is strong

## Phase 8: data trust and expanded research universe

- Add data freshness/source confidence checks
- Make fallback/mock data obvious in the UI
- Expand default stocks/ETFs for broader opportunity research
- Keep opportunity labels research-only, not trade instructions

## Phase 9: future asset-class research tracks

- Add crypto data expansion for BTC/ETH-style research workflows
- Add futures research mode using proxies before direct futures contracts
- Add a prediction-market/Polymarket research tracker without execution
- Add sports analytics as a separate legal/compliance-sensitive research module

## Phase 10: gated execution roadmap only

- Real-money execution is future gated work only
- Require explicit legal, compliance, provider, and safety design before any integration
- Do not add broker, exchange, odds, or live execution APIs in the current research app
